TaskMapper 必須
タスクマッパーの全メソッド
メソッド名 引数 戻り値 SQL種別 備考
selectAll なし List<Task> SELECT 全件取得、作成日時降順
selectById Long id Task SELECT 主キー検索
selectByUserId Long userId List<Task> SELECT 外部キー検索
insert Task task void INSERT @Options(useGeneratedKeys=true)
update Task task void UPDATE updated_atも更新
updateStatus Long id, String status void UPDATE ステータスのみ更新
delete Long id void DELETE 物理削除
search String keyword List<Task> SELECT LIKE検索（title, content）
countByUserId Long userId int SELECT ユーザー別件数取得
