2. パッケージの役割

パッケージ 役割 主なファイル
config アプリケーション全体の設定、認証・認可、初期データ整備を担当します。 SecurityConfig, DataInitializer
controller HTTPリクエストを受け取り、Model作成、View選択、リダイレクトを行います。 PublicController, ManagementController, LoginController
service 予約、在庫、商品、顧客、認証補助などの業務ロジックを担当します。 ReservationService, InventoryService, TotpService
repository DBへの検索、登録、更新、論理削除を担当します。 ReservationRepository, ProductRepository, CustomerRepository
entity DBテーブルに対応するデータモデルを定義します。 Reservation, Customer, Product, InventoryItem
form 画面入力値と入力チェック項目を保持します。 ReservationRequest
