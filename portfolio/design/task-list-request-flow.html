Request Flow / Task List

タスク一覧表示機能 リクエスト処理フロー

タスク一覧画面を表示する際の、ブラウザからController、Service、Mapper、Database、Thymeleafテンプレートまでの処理順序を示します。 データの流れとして List<Task> がMapperからService、Controller、Viewへ渡されます。

2. 処理手順

  1. 1. リクエスト送信: Client（ブラウザ）がタスク一覧URLへGETリクエストを送信します。
  2. 2. Controller呼び出し: TaskController.list() がリクエストを受け取り、一覧データ取得のために TaskService.findAll() を呼び出します。
  3. 3. Service処理: TaskService.findAll() は業務処理の入口として、DB取得処理を TaskMapper.selectAll() に委譲します。
  4. 4. DBアクセス: TaskMapper.selectAll() がDatabaseへSELECTを実行し、タスク行データを取得します。
  5. 5. データ返却: Databaseの結果は List<Task> としてMapper、Service、Controllerへ順に返却されます。
  6. 6. 画面生成: Controllerが List<Task> をModelに格納し、レスポンスとして list.html を返します。
  7. 7. 表示: Thymeleafが list.html に List<Task> を展開し、Client（ブラウザ）に一覧画面を表示します。
