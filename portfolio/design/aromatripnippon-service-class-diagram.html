AromaTripNippon Service クラス図・メソッド詳細

作成日: 2026-06-04 対象: com.aromatripnippon.service 形式: Spring Service + Spring Data JPA Repository
AromaTripNippon プロジェクトの Service クラスを、クラス図風の構造とメソッド詳細表で整理した資料です。 このプロジェクトでは TaskMapper のような MyBatis Mapper は使用されておらず、各Serviceは Spring Data JPA の Repository に依存しています。 表のSQL種別は、Service内で呼び出すRepository操作から見た代表的なDB操作を記載しています。
FormからEntityへの変換: 明示的なFormクラスは ReservationRequest です。公開予約では PublicController が ReservationRequest から Customer と Reservation を生成し、 ReservationService#createReservation に渡します。管理画面では多くの画面がEntityを直接フォームバインドし、 編集時は既存Entityへsetterで入力値を反映してからServiceの save 系メソッドへ渡します。
