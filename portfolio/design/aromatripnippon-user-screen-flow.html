AromaTripNippon 利用者機能 画面遷移図

利用者が公開サイトを閲覧し、体験内容の確認から予約フォーム送信、予約完了画面へ進む流れをURLパス付きで示します。

1. ASCII画面遷移図

+----------------------------------------------------------------------------------+
|                              利用者機能（公開サイト）                            |
+----------------------------------------------------------------------------------+

  [トップページ]
  /
        | ナビゲーション
        +---------------------------> [コンセプト]
        |                              /concept
        |
        +---------------------------> [体験紹介]
        |                              /experience
        |                                     |
        |                                     | 予約する
        |                                     v
        +---------------------------> [予約フォーム]
                                       /reservation
                                             |
                                             | POST /reservation
                                             | 入力エラーあり
                                             +--------------------+
                                             |                    |
                                             v                    |
                                      [予約フォーム] <------------+
                                      /reservation
                                             |
                                             | 入力OK
                                             | redirect
                                             v
                                      [予約完了]
                                      /reservation/complete/{id}


  [English Top]
  /en または /en/
        | Navigation
        +---------------------------> [Concept]
        |                              /en/concept
        |
        +---------------------------> [Experience]
        |                              /en/experience
        |                                     |
        |                                     | Reserve
        |                                     v
        +---------------------------> [Reservation Form]
                                       /en/reservation
                                             |
                                             | POST /en/reservation
                                             | validation error
                                             +--------------------+
                                             |                    |
                                             v                    |
                                      [Reservation Form] <--------+
                                      /en/reservation
                                             |
                                             | success / redirect
                                             v
                                      [Reservation Complete]
                                      /en/reservation/complete/{id}
