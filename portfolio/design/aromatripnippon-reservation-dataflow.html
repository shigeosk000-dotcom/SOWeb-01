1 全体像

このフローは BeanUtils ではなく手動マッピングで実装されています。
フォーム入力は @ModelAttribute で ReservationRequest にバインドされ、その後 PublicController で Customer と Reservation に分解してセットします。保存は MyBatis の @Insert ではなく、Spring Data JPA の JpaRepository.save() です。

1. Form

  • ReservationRequest に自動バインド
  • visitDate は LocalDate
  • guestCount は Integer

2. Controller

  • Customer / Reservation を new する
  • 値は setXXX() で手動コピー
  • 言語は normalizePreferredLanguage() で補正

3. Service

  • 日付範囲をチェック
  • active な ExperienceProgram を取得
  • @Transactional の中で保存

4. DB

  • customers に顧客を保存
  • reservations に予約を保存
  • experience_programs は参照のみ

4 型変換とマッピング方法

変換ルール 重要
この実装で実際に行っている変換だけを並べています。
変換元 変換先 方法 実装箇所 補足
HTML date input の文字列 ReservationRequest.visitDate: LocalDate Spring MVC の自動バインド @ModelAttribute JPA 側では LocalDate のまま扱う
セレクトの値文字列 ReservationRequest.guestCount: Integer Spring MVC の型変換 @ModelAttribute 1 - 4 の数値に変換
ReservationRequest Customer / Reservation 手動マッピング PublicController#createReservation() setName() などで代入
preferredLanguage の文字列 日本語 / 英語 正規化 normalizePreferredLanguage() 入力ゆれを吸収
Reservation.visitDate: LocalDate reservation_date: DATE JPA / Hibernate Reservation Entity 列定義は @Column(name = "reservation_date")
BaseEntity.createdAt / updatedAt created_at / updated_at: TIMESTAMP @PrePersist / @PreUpdate BaseEntity 新規保存時に自動セット

このフローでは BeanUtils.copyProperties() は使っていません。保存は MyBatis の @Insert ではなく、JPA の save() です。

5 保存方法と実コード

保存処理 実装どおり
予約保存の本体は ReservationService#createReservation() です。
// ReservationService#createReservation()
@Transactional
public Reservation createReservation(Reservation reservation, @Valid Customer customer) {
  LocalDate today = LocalDate.now();
  LocalDate maxDate = today.plusMonths(3);

  // 日付バリデーション
  if (reservation.getVisitDate() == null || reservation.getVisitDate().isBefore(today)) {
    throw new IllegalArgumentException("予約日は本日以降を選択してください。");
  }
  if (reservation.getVisitDate().isAfter(maxDate)) {
    throw new IllegalArgumentException("予約日は本日から3か月先まで選択できます。");
  }

  // 1) Customer を先に保存
  Customer savedCustomer = customers.save(customer);

  // 2) active な体験プログラムを取得
  ExperienceProgram program = programs.findFirstByDeletedAtIsNullAndActiveTrueOrderById()
      .orElseThrow(() -> new IllegalStateException("Active experience program is not configured."));

  // 3) 予約 Entity に関連オブジェクトをセット
  reservation.setCustomer(savedCustomer);
  reservation.setExperienceProgram(program);
  reservation.setStatus("RESERVED");

  // 4) reservations テーブルへ保存
  return reservations.save(reservation);
}
Repository の役割 補足
保存に使うのは JPA の save()、参照に使うのは repository の query メソッドです。
Repository 主な用途 保存 / 参照 備考
CustomerRepository Customer の保存 save(customer) JpaRepository を継承
ReservationRepository Reservation の保存 / 参照 save(reservation) 一覧取得や soft delete 用の query あり
ExperienceProgramRepository active な体験プログラムの取得 参照のみ findFirstByDeletedAtIsNullAndActiveTrueOrderById()
