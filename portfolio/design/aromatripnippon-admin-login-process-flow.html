Admin Login Flow / IF-THEN-ELSE Logic

AromaTripNippon 管理機能ログイン処理フローチャート

管理画面ログインの入力チェック、管理ユーザー存在チェック、BCryptパスワード照合、SecurityContext保存、 エラー時のログイン画面復帰、パスワード紛失時の再設定、SQLインジェクション等への防御をASCII形式で整理します。

POST /management/login GET /management/forgot-password Spring Security AdminUserRepository BCryptPasswordEncoder

1. 判定ポイント

ログイン入力

  • ログインIDとパスワードの空チェックを行う。
  • CSRFトークン不正、極端な長さ、制御文字などの異常入力を拒否する。
  • エラー内容は詳細化せず、ログイン画面へ戻す。

ユーザー検索

  • findByLoginIdAndDeletedAtIsNullAndActiveTrueで有効な管理者を検索する。
  • 存在しない場合もパスワード誤りと同じメッセージにする。
  • SQL文字列連結ではなく、Spring Data JPAのパラメータバインドを使う。

パスワード照合

  • BCryptPasswordEncoder.matchesで入力値とハッシュを照合する。
  • 失敗時は失敗回数を加算し、5回以上でロック・再設定必須にする。
  • 成功時は失敗回数を0に戻す。

認証成功・紛失対応

  • 認証成功時はSpring SecurityがSecurityContextに認証情報を保存する。
  • 成功後は/management/dashboardへリダイレクトする。
  • パスワード紛失時はTOTPまたはバックアップコード確認後に再設定する。

3. IF-THEN-ELSE形式の疑似コード

// 管理機能ログイン処理
FUNCTION managementLogin(username, password, csrfToken, request)

  errors = []

  // CSRF・攻撃入力チェック
  IF csrfToken が不正 THEN
    AuditLog に「CSRF不正」を記録
    errors に「ログイン情報が正しくありません」を追加
    RETURN ログイン画面（エラー表示）
  END IF

  username = trim(username)

  // 入力値の空チェック
  IF username が空 THEN
    errors に「ログインIDを入力してください」を追加
  END IF

  IF password が空 THEN
    errors に「パスワードを入力してください」を追加
  END IF

  IF errors が空でない THEN
    RETURN ログイン画面（エラー表示）
  END IF

  // SQLインジェクション等の攻撃対応
  IF username が長すぎる OR password が長すぎる OR 制御文字を含む THEN
    AuditLog に「異常なログイン入力」を記録
    errors に「ログイン情報が正しくありません」を追加
    RETURN ログイン画面（エラー表示）
  END IF

  // 重要: 入力値をSQL文字列へ連結しない。Spring Data JPAのパラメータバインドで検索する。
  user = AdminUserRepository.findByLoginIdAndDeletedAtIsNullAndActiveTrue(username)

  // ユーザーの存在チェック
  IF user が null THEN
    errors に「ログインIDまたはパスワードが正しくありません」を追加
    RETURN ログイン画面（エラー表示）
  END IF

  // ロック状態チェック
  IF user.accountLocked が true OR user.passwordResetRequired が true THEN
    errors に「アカウントがロックされています。パスワード再設定後にログインしてください」を追加
    RETURN ログイン画面（ロック表示）
  END IF

  // パスワードの照合
  IF BCryptPasswordEncoder.matches(password, user.passwordHash) が false THEN
    user.failedLoginAttempts = user.failedLoginAttempts + 1

    IF user.failedLoginAttempts が 5以上 THEN
      user.accountLocked = true
      user.passwordResetRequired = true
      AdminUserRepository.save(user)
      errors に「アカウントがロックされました」を追加
      RETURN ログイン画面（ロック表示）
    ELSE
      AdminUserRepository.save(user)
      errors に「ログインIDまたはパスワードが正しくありません」を追加
      RETURN ログイン画面（エラー表示）
    END IF
  END IF

  // 認証成功時の処理
  authentication = Authentication(user.loginId, user.role)
  SecurityContextHolder.getContext().setAuthentication(authentication)

  user.failedLoginAttempts = 0
  AdminUserRepository.save(user)

  RETURN リダイレクト("/management/dashboard")

END FUNCTION


// パスワード紛失時の処理
FUNCTION forgotPassword(loginId, newPassword, confirmPassword, totpCode, backupCode)

  errors = []
  loginId = trim(loginId)

  IF loginId が空 THEN
    errors に「ログインIDを入力してください」を追加
  END IF

  IF newPassword が空 OR newPassword が8文字未満 THEN
    errors に「新しいパスワードは8文字以上で入力してください」を追加
  END IF

  IF newPassword と confirmPassword が一致しない THEN
    errors に「確認用パスワードが一致しません」を追加
  END IF

  IF errors が空でない THEN
    RETURN パスワード再設定画面（エラー表示）
  END IF

  admin = AdminUserRepository.findByLoginIdAndDeletedAtIsNullAndActiveTrue(loginId)

  IF admin が null OR admin.totpEnabled が false OR admin.totpSecret が null THEN
    errors に「入力内容が正しくありません」を追加
    RETURN パスワード再設定画面（エラー表示）
  END IF

  verified = TotpService.verifyCode(admin.totpSecret, totpCode)
             OR TotpService.consumeBackupCode(admin, backupCode)

  IF verified が false THEN
    errors に「認証コードまたはバックアップコードが正しくありません」を追加
    RETURN パスワード再設定画面（エラー表示）
  END IF

  admin.passwordHash = BCryptPasswordEncoder.encode(newPassword)
  admin.failedLoginAttempts = 0
  admin.accountLocked = false
  admin.passwordResetRequired = false
  admin.passwordResetTokenHash = null
  admin.passwordResetTokenExpiresAt = null
  AdminUserRepository.save(admin)

  RETURN リダイレクト("/management/login?reset")

END FUNCTION

4. エラー・攻撃対応まとめ

ケース 判定 処理
入力値が空 ログインIDまたはパスワードが未入力 エラーを表示して/management/loginへ戻る。
ユーザーなし 有効な管理者ユーザーが見つからない ユーザー列挙を防ぐため、パスワード誤りと同じ汎用エラーを表示する。
パスワード不一致 BCrypt照合が失敗 失敗回数を加算し、5回以上でロックしてログイン画面へ戻る。
SQLインジェクション等 異常な入力、CSRF不正、過度な長さ、制御文字など 監査ログに記録し、SQLは必ずパラメータバインドで実行する。画面には汎用エラーのみ表示する。
パスワード紛失 ログイン画面の「パスワードを忘れた場合」から再設定へ遷移 TOTPまたはバックアップコード確認後、BCryptで新パスワードを保存し、ログイン画面へ戻る。
認証成功 ユーザー存在、未ロック、パスワード一致 SecurityContextへ認証情報を保存し、/management/dashboardへリダイレクトする。

実装ではSpring SecurityのUsernamePasswordAuthenticationFilter、 DaoAuthenticationProvider、AuthenticationSuccessHandler、 AuthenticationFailureHandlerが上記の流れを分担します。
