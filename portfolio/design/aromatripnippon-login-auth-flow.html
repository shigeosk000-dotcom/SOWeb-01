Authentication Flow / Spring Security

AromaTripNippon ログイン認証フロー

管理者ログイン時に使用されるSpring Securityの主要コンポーネントと、認証成功・失敗時の画面遷移をASCII図で示します。 実装上のログイン処理URLは /management/login、成功時の遷移先は /management/dashboard です。

2. 使用コンポーネント

コンポーネント 実装・設定 役割
ログイン画面 LoginController / management/login.html GET /management/login でログインフォームを表示します。
SecurityFilterChain SecurityConfig.securityFilterChain() /management/** を認証必須にし、フォームログインを設定します。
UsernamePasswordAuthenticationFilter loginProcessingUrl("/management/login") フォームのユーザー名・パスワードを受け取り、認証処理を開始します。
AuthenticationManager ProviderManager 認証処理を DaoAuthenticationProvider に委譲します。
DaoAuthenticationProvider PasswordEncoder と UserDetailsService DBから取得したユーザー情報と入力パスワードを照合します。
UserDetailsService loadUserByUsername(username) AdminUserRepository から有効な管理者ユーザーを取得します。
Repository / Database AdminUserRepository / admin_users ログインID、パスワードハッシュ、ロール、ロック状態を参照・更新します。
成功時ハンドラ AuthenticationSuccessHandler 失敗回数を0に戻し、/management/dashboard へリダイレクトします。
失敗時ハンドラ AuthenticationFailureHandler 失敗回数を加算し、通常は /management/login?error、ロック時は /management/login?locked へ戻します。
