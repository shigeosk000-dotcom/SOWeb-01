2. データの流れ

  1. 画面表示: ブラウザがURLへGETリクエストを送信し、ControllerがServiceまたはRepositoryから表示データを取得してModelへ格納します。
  2. 業務処理: Controllerはフォーム入力を検証し、予約登録、在庫更新、商品管理、顧客管理などの処理をService層へ委譲します。
  3. 永続化: Service層はRepository層を呼び出し、MySQLに対して検索、登録、更新、論理削除などのDBアクセスを行います。
  4. 結果返却: DB結果はRepository、Service、Controllerの順に戻り、ControllerがThymeleafビュー名とModelを返します。
  5. HTML生成: ThymeleafがModelの値をHTMLへ展開し、ブラウザへHTML/CSS/JSとして返却します。

3. レイヤー別構成要素

レイヤー 主な構成要素 役割
クライアント ブラウザ 公開ページ閲覧、予約フォーム送信、管理画面操作を行います。
Controller層 PublicController, ManagementController, LoginController HTTPリクエストを受け取り、入力検証、Model作成、Service呼び出し、View選択を行います。
Service層 ReservationService, InventoryService, ProductService, CustomerService など 予約、在庫、商品、顧客、調香レシピ、管理者、監査ログなどの業務ロジックを担当します。
Repository層 ReservationRepository, ProductRepository, InventoryItemRepository, CustomerRepository など MySQLへのCRUD、検索、論理削除、集計などのデータアクセスを担当します。
データベース MySQL / aromatripnippon_phase1 予約、顧客、商品、在庫、体験プログラム、管理者、監査ログなどのデータを保存します。
Thymeleafビュー templates/public/*.html, templates/management/*.html Controllerから渡されたModelをHTMLに展開し、ブラウザへ画面を返します。
