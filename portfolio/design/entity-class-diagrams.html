AromaTripNippon Entity クラス図

AromaTripNippon の主要Entityを、BaseEntityから継承する共通項目とあわせて整理したクラス図です。
AdminUser.java 必須 管理者ログイン、権限、二要素認証、パスワード再設定情報を保持するEntity。 
┌──────────────────────────────────────────────────────────────┐
│                           «Entity»                           │
│                          AdminUser                           │
├──────────────────────────────────────────────────────────────┤
│ - loginId: String                                            │
│ - displayName: String                                        │
│ - email: String                                              │
│ - passwordHash: String                                       │
│ - role: String                                               │
│ - active: Boolean                                            │
│ - notificationSetting: String                                │
│ - displayLanguage: String                                    │
│ - failedLoginAttempts: Integer                               │
│ - accountLocked: Boolean                                     │
│ - passwordResetRequired: Boolean                             │
│ - passwordResetTokenHash: String                             │
│ - passwordResetTokenExpiresAt: LocalDateTime                 │
│ - totpEnabled: Boolean                                       │
│ - totpSecret: String                                         │
│ - totpPendingSecret: String                                  │
│ - id / createdAt / updatedAt / deletedAt                     │
├──────────────────────────────────────────────────────────────┤
│ + getter/setter (Lombok @Data)                               │
└──────────────────────────────────────────────────────────────┘
Lombok: @Data, @NoArgsConstructor, @AllArgsConstructor

BaseEntity.java 各Entityに共通するID、作成日時、更新日時、論理削除日時を定義する親クラス。 
┌──────────────────────────────────────────────────────────────┐
│                      «MappedSuperclass»                      │
│                          BaseEntity                          │
├──────────────────────────────────────────────────────────────┤
│ - id: Long                                                   │
│ - createdAt: LocalDateTime                                   │
│ - updatedAt: LocalDateTime                                   │
│ - deletedAt: LocalDateTime                                   │
├──────────────────────────────────────────────────────────────┤
│ + prePersist(): void                                         │
│ + preUpdate(): void                                          │
│ + softDelete(): void                                         │
│ + isDeleted(): boolean                                       │
│ + getter/setter                                              │
└──────────────────────────────────────────────────────────────┘
JPA: @MappedSuperclass。各Entityの共通フィールドと論理削除処理をまとめます。
