AromaTripNippon Controller メソッド一覧

作成日: 2026-06-04 対象: com.aromatripnippon.controller 観点: RESTful CRUD と画面遷移
Controller をクラス単位でまとめ、各メソッドの HTTP メソッド、URL、引数、戻り値、処理概要を一覧化したページです。 長い引数や説明文はこのページ内で折り返し、親ページでは iframe でそのまま差し込んで使う前提にしています。
RESTful な URL 設計 一覧は GET /management/{resources}、新規は GET /management/{resources}/new、 作成は POST /management/{resources}、詳細は GET /management/{resources}/{id}、 編集は GET /management/{resources}/{id}/edit、更新は POST /management/{resources}/{id}、 削除は POST /management/{resources}/{id}/delete を基本としています。
目次
  1. PublicController
  2. LoginController
  3. ManagementController
PublicController 公開ページと予約登録を担当する Controller
責務: 公開サイト表示 CRUD: 予約作成 言語: 日本語 / 英語
メソッド名 HTTP URL 引数 戻り値 処理概要
index GET / Model model String 先頭の公開プログラムを Model に詰めて public/index を表示する。
indexEn GET /en, /en/ Model model String 英語版のトップページを表示する。
experience GET /experience Model model String 体験紹介ページにプログラム情報を追加して表示する。
experienceEn GET /en/experience Model model String 英語版の体験紹介ページを表示する。
concept GET /concept なし String コンセプトページをそのまま返す。
conceptEn GET /en/concept なし String 英語版コンセプトページを返す。
reservation GET /reservation Model model String 予約フォーム用の ReservationRequest を初期化し、日付制約とプログラム情報を渡す。
reservationEn GET /en/reservation Model model String 英語版の予約フォームを初期化して表示する。
createReservation POST /reservation @Valid @ModelAttribute ReservationRequest reservationRequest, BindingResult errors, Model model, RedirectAttributes redirectAttributes String 入力を検証し、顧客と予約を作成して完了画面へリダイレクトする。
createReservationEn POST /en/reservation @Valid @ModelAttribute ReservationRequest reservationRequest, BindingResult errors, Model model, RedirectAttributes redirectAttributes String 英語版の入力を検証し、英語メッセージ付きで予約を作成する。
complete GET /reservation/complete/{id} @PathVariable Long id, Model model String 削除済みでない予約を取得し、完了ページを表示する。
completeEn GET /en/reservation/complete/{id} @PathVariable Long id, Model model String 英語版の予約完了ページを表示する。
LoginController 管理者ログインとパスワード再設定を担当する Controller
責務: 認証導線 CRUD: なし TOTP: パスワード再設定で利用
メソッド名 HTTP URL 引数 戻り値 処理概要
login GET /management/login なし String 管理画面のログインページを表示する。
forgotPassword GET /management/forgot-password なし String パスワード再設定フォームを表示する。
forgotPasswordSubmit POST /management/forgot-password @RequestParam String loginId, @RequestParam String newPassword, @RequestParam String confirmPassword, @RequestParam(required = false) String totpCode, @RequestParam(required = false) String backupCode, Model model, RedirectAttributes redirectAttributes String 新しいパスワードと TOTP/バックアップコードを検証し、管理者パスワードを更新してログイン画面へ戻す。
