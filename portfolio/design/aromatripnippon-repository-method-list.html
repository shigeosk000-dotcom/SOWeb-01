AromaTripNippon Repository メソッド一覧

作成日: 2026-06-04 対象: com.aromatripnippon.repository 観点: MyBatis 風の一覧表示だが実装は Spring Data JPA 派生クエリ
Repository インターフェースで宣言されているメソッドを、SQL 種別と備考つきで一覧化しています。 実装は Spring Data JPA の派生クエリと @Query / @Modifying ですが、一覧では読みやすさのため MyBatis 風の観点で整理しています。
SQL 種別の扱い 派生クエリは基本的に SELECT、@Modifying の更新クエリは UPDATE として記載しています。 save や delete など JpaRepository 継承の標準メソッドは、各 Repository に明示的な宣言がないためこの一覧には含めていません。
