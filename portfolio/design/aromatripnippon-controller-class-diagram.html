AromaTripNippon Controller クラス図・エンドポイント一覧

作成日: 2026-06-04 対象: com.aromatripnippon.controller 形式: Spring MVC Controller
AromaTripNippon プロジェクトの Controller クラスを、クラス図風の構造とエンドポイント一覧で整理した資料です。 URLは公開サイト系、管理画面系、認証系に分かれ、管理画面の更新・削除はHTMLフォーム前提のため POST で実装されています。
RESTfulなURL設計: 一覧は GET /management/{resources}、新規フォームは GET /management/{resources}/new、 作成は POST /management/{resources}、詳細は GET /management/{resources}/{id}、 編集フォームは GET /management/{resources}/{id}/edit、更新は POST /management/{resources}/{id}、 削除は POST /management/{resources}/{id}/delete の形で統一されています。

│ + handleNoSuchElement(ex, request, redirect): String         │

対象: ManagementController。URLマッピングではなく、例外発生時にSpring MVCから呼び出される。
HTTPURLハンドラ表示/遷移処理概要
例外NoSuchElementExceptionhandleNoSuchElementredirect:{referer or /management/dashboard}対象データが見つからない場合にエラーメッセージをFlash属性へ設定し、参照元の管理画面へ戻す。
例外IllegalStateExceptionhandleIllegalStateredirect:{referer or /management/dashboard}処理継続できない状態の例外に対してエラーメッセージを設定し、参照元の管理画面へ戻す。
