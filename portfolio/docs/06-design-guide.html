1 デザインコンセプト

デザインキーワード

余白のある上質さ：

　全体的に要素を詰め込みすぎず、「安く見せない」「体験価値を高く見せる」設計としている


ストーリーで魅せる体験設計：

　TOP → コンセプト → 体験 → 予約 の流れが明確になる設計としている


五感に訴えるリアリティ：

　本サービスの本質は「香り＝体験」。体験者の写真により視覚だけでなく“想像させる設計”にしている

5 レイアウトルール

レイアウト基本ルール

レイアウトルール一覧

項目 推奨値 CSS例 用途・意図
コンテンツ最大幅 1120px .container { width: min(1120px, calc(100% - 32px)); } 横に広がりすぎず上質な読みやすさを確保
左右余白 16px〜32px calc(100% - 32px) スマホでも端に寄りすぎない余白設計
グリッド 2カラム / 3カラム .grid-2 { grid-template-columns: 1fr 1fr; } ヒーロー・カード表示に使用
ガター幅 16px〜24px gap: 16px; 要素間の適切な距離感を保つ
セクション余白 40px〜56px .section { padding: 40px 0; } セクションの区切りを明確にする
要素間余白 8px〜16px margin-bottom: 8px; テキストやボタンの間隔
カード内余白 24px .card { padding: 24px; } 情報を読みやすく整理
角丸（大） 18px border-radius: 18px; カード・画像枠
角丸（中） 16px border-radius: 16px; カードコンポーネント
角丸（小） 14px border-radius: 14px; 入力欄・フォーム
ピル・ボタン角丸 999px border-radius: 999px; ボタン・タグの柔らかさ演出
シャドウ 0 8px 24px rgba(0,0,0,.08) box-shadow: 0 8px 24px rgba(0,0,0,.08); 軽い浮き感で上質な印象を演出
境界線 1px #e8dccb border: 1px solid #e8dccb; 柔らかい区切り線
PCブレークポイント 901px以上 @media (min-width: 901px) 2〜3カラム表示
タブレット 601px〜900px @media (max-width: 900px) 1カラム化開始
スマートフォン 600px以下 @media (max-width: 600px) 完全モバイルレイアウト
