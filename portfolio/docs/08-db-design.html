Phase1（更新後）テーブル要約

テーブル名 用途 主な関連
product_categories 商品カテゴリ（カテゴリ名、表示順、有効状態）を管理。初期値は「製品」「素材」「容器」。 products.category の選択元。
products 商品マスタ。カテゴリは product_categories の登録値から選択し、products.category に保持。 product_categories を参照、inventory_items と関連。
inventory_items 商品単位の在庫実体（在庫数、閾値、保管場所、仕入先、最終入荷日、コメント）。 products と1対1、inventory_transactions と1対多。
inventory_transactions 在庫増減履歴を記録。 inventory_items と多対1。
fragrance_recipe_materials レシピ素材明細。選択可能素材は在庫品目と商品カテゴリの運用ルールに従う。 fragrance_recipes と多対1、products と多対1。
customers / reservations 顧客情報と予約情報を管理。 顧客1件に対して予約は複数。
admin_users / audit_logs 管理者認証・監査ログ管理。 管理者1件に対して監査ログは複数。

Phase2 追加テーブル概要

テーブル名 用途 主なリレーション
user_accounts マイページ利用者のログインアカウントを管理する。 customers と多対1、orders と1対多。
orders EC注文情報を管理する。 customers、user_accounts と多対1、order_items と1対多。
order_items 注文内の商品明細を管理する。 orders と多対1、products と多対1、必要に応じて fragrance_recipes と多対1。
reviews 体験または商品に対するレビュー・口コミを管理する。 customers、reservations、products と関連。
gallery_posts ギャラリー表示用の写真、動画、SNS風投稿、体験事例を管理する。 reviews、reservations と多対1。
localization_messages 多言語表示用の画面文言、予約メール文言、案内文を管理する。 他テーブルとは直接FKを持たず、message_key と language_code で参照する。

Phase1 / Phase2 差分

分類 Phase1 Phase2
予約 予約登録、予約管理、顧客紐づけ。 Phase1と同様。マイページからの予約履歴表示を追加。
顧客 管理画面で顧客情報を管理。 ユーザーアカウントを追加し、マイページログインに対応。
香りレシピ 管理画面で顧客ごとの香りレシピを管理。 マイページでレシピ閲覧、同じ香りの再注文に利用。
商品・在庫 商品情報と在庫を管理。 EC注文、注文明細、購入履歴と連携。
EC 対象外または商品管理のみ。 注文、注文明細、決済状況、発送状況を管理。
レビュー 固定表示または簡易表示。 レビュー投稿、公開管理、ギャラリー連携を追加。
多言語 画面内固定文言中心。 多言語文言管理テーブルで画面文言・メール文言を管理。

2 テーブル定義

テーブル定義書

本定義書は、Phase1時点の予約・顧客・香りレシピ・商品・在庫管理、および Phase2時点のEC注文、マイページ、レビュー、ギャラリー、多言語管理を含むテーブル定義である。


customers（顧客）

カラム名 日本語名 データ型 NULL許可 デフォルト値 制約 説明
id 顧客ID BIGINT 不可 自動採番 PK 顧客を一意に識別するID。
name 氏名 VARCHAR(100) 不可 なし NOT NULL 予約者・体験参加者の氏名。
nationality 国籍 VARCHAR(50) 可 NULL - 顧客の国籍。
email メールアドレス VARCHAR(255) 不可 なし NOT NULL 予約確認やマイページログインに利用するメールアドレス。
phone 電話番号 VARCHAR(30) 可 NULL - 連絡先電話番号。
preferred_language 希望言語 VARCHAR(30) 可 'English' - 接客・通知に使用する希望言語。
purpose 利用目的 VARCHAR(100) 可 NULL - 観光、カップル体験、再購入相談など。
note 備考 TEXT 可 NULL - 管理者用メモ。
created_at 作成日時 TIMESTAMP 不可 CURRENT_TIMESTAMP NOT NULL レコード作成日時。
updated_at 更新日時 TIMESTAMP 不可 CURRENT_TIMESTAMP NOT NULL レコード更新日時。
deleted_at 削除日時 TIMESTAMP 可 NULL 論理削除 顧客情報を論理削除した日時。

updated_at 更新日時 TIMESTAMP 不可 CURRENT_TIMESTAMP NOT NULL レコード更新日時。

補足

  • 上記の BCrypt ハッシュ値は、開発・検証用の固定パスワード(password)を想定したサンプル値である。
  • 本番環境では、初期パスワードを利用者に通知後、初回ログイン時に変更させる運用が望ましい。
  • product_categories テーブルは商品カテゴリマスタとして追加し、初期データとして「製品」「素材」「容器」を登録する。
  • H2で利用する場合、BOOLEAN、CURRENT_TIMESTAMP、CURRENT_DATE はそのまま利用可能な想定である。
