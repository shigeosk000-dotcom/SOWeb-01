機能詳細仕様書：トップページ表示（モックアップ準拠）

フロントエンド user / index.html Phase1 Must

機能概要：添付モックアップの mockup/user/index.html をベースに、訪日外国人旅行者・体験ユーザーへサービスの世界観、素材、体験の流れ、口コミ、予約導線を表示する。

1. 画面レイアウト

3. 処理フロー

ユーザー操作ブラウザで user/index.html にアクセスする。

画面読込HTML、styles.css、画像アセットを読み込む。

初期化処理DOMContentLoaded後、.pro-slider を取得し、スライド一覧、前後ボタン、ドットボタン、表示間隔を初期化する。

入力チェックスライダー表示間隔、スライド件数、画像パス、リンクURLの妥当性を確認する。

表示処理ヘッダー、ヒーロー、ブランドストーリー、日本素材、体験の流れ、レビュー、予約CTA、フッターを順に表示する。

ユーザー操作「予約する」「Book Experience」「コンセプトを読む」「詳しく見る」「予約ページへ進む」等を押下する。

遷移処理クリックされたリンクのhrefに従い、concept.html、experience.html、reservation.html等へ遷移する。

4. 正常時の動作

正常表示

  • トップページアクセス時、ヘッダーからフッターまでモックアップと同じ順序で表示する。
  • ヒーロースライダーは初期表示で1枚目を表示し、5秒間隔で次スライドへ自動切替する。
  • 前へ / 次へボタン押下時、スライドを前後に切替し、自動切替タイマーを再起動する。
  • ドットナビ押下時、指定されたスライドへ切替し、aria-selectedを更新する。
  • 「予約する」「Book Experience」「予約ページへ進む」押下時、reservation.htmlへ遷移する。
  • 「コンセプト」「コンセプトを読む」「詳しく見る」押下時、concept.htmlへ遷移する。
  • 「体験詳細」押下時、experience.htmlへ遷移する。
  • レビュー、素材カード、体験ステップは固定コンテンツとして表示する。

5. エラー時の動作

バリデーションエラー

  • リンクURLが想定外の場合、画面描画前に該当リンクを非活性または非表示にする。
  • スライダー表示間隔が数値でない場合、DOMContentLoaded時にデフォルト値5000msを使用する。
  • スライド番号が範囲外の場合、スライダー操作時に循環処理で先頭または末尾に補正する。
  • 外部SNS URLがhttps://以外の場合、画面描画前にリンク化せずテキスト表示にする。
  • レビュー文や表示文言にHTMLタグが含まれる場合、画面描画前にエスケープして表示する。

システムエラー・読込エラー

  • CSS読込に失敗した場合、ブラウザ標準表示になるが、HTML構造とリンク遷移は維持する。
  • 画像読込に失敗した場合、altテキストを表示し、ページ全体の表示は継続する。
  • JavaScript実行時エラーが発生した場合、スライダーの自動切替は停止するが、初期表示とリンク遷移は利用可能とする。
  • リンク先HTMLが存在しない場合、ブラウザの404またはファイル未検出画面を表示する。

7. DB変更反映メモ（2026-05-14）

  • 商品マスタは category_master を参照し、products は category_id + master_id を業務キーとして扱う。
  • 在庫は商品と1:1（inventory_items.product_id）で管理し、増減履歴は inventory_transactions に記録する。
  • 予約/顧客は reservations と customers の紐づきを前提とし、Phase2対象テーブル（orders/order_items/reviews 等）はPhase1機能では使用しない。
